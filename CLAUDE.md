## Stack / build / test / run

### Rebuild stack

- Vite 7 + strict TypeScript, vanilla (no framework)
- GSAP + ScrollTrigger for scroll-driven animation
- xterm.js (`@xterm/xterm`, fit + web-links addons) for the terminal
- Vitest for tests (`src/**/*.test.ts`, node environment)
- sharp + tsx for scripts (e.g. placeholder frame generation)
- Node **20+**

npm scripts:

| Script | What it does |
| --- | --- |
| `npm run dev` | Vite dev server (serves `/assets/frames/*` from `assets/frames/` if present) |
| `npm run build` | `tsc --noEmit` then `vite build` (copies `assets/frames/` to `dist/` if present) |
| `npm run preview` | Preview the production build |
| `npm test` | `vitest run` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run frames:placeholder` | Generate placeholder frames into `public/placeholder-frames/` (`-- --if-missing` skips when present) |

`predev` and `prebuild` run `frames:placeholder -- --if-missing`, so placeholders are generated automatically when missing.

## Asset contract (READ-ONLY)

Full spec: [`docs/asset-contract.md`](docs/asset-contract.md) (schema v1; sample in `docs/manifest.sample.json`).

- **Visual Asset Producer (VAP) owns `assets/frames/`**, including `assets/frames/manifest.json`. Claude Code may **consume** them; never edit, move, delete, or regenerate them. We only commit them unchanged as delivered.
- Contract changes are proposed in the team chat and agreed first; then update the doc, sample, `src/frames/manifest.ts` and tests together.
- Layout: `assets/frames/<clip>/<desktop|mobile>/0001.webp`; manifest paths are relative to `assets/frames/`.
- `src/frames/manifest.ts`: types, `parseManifest` validator (reports all problems), `framePath`, `resolveHeroFrame`, `buildTimeline` (pure, no DOM).
- The app loads `/assets/frames/manifest.json` when present, else the placeholder fallback `/placeholder-frames/manifest.json`. Override with `VITE_FRAMES_BASE`.
- **The placeholder fallback is ours**: `public/placeholder-frames/` is generated by `npm run frames:placeholder` and **gitignored** — never commit it, never write it into `assets/frames/`.

## Code style and quality bar

- TypeScript, strict mode.
- Small focused commits; clear messages; no drive-by refactors or unexplained new dependencies (say why before adding any).
- Tests for core logic.
- Lighthouse **90+** on mobile for performance, accessibility, best practices, and SEO.
- Accessibility: semantic HTML, keyboard navigation, visible focus states, `prefers-reduced-motion` respected for scroll animations, alt text, sufficient contrast.
