## Asset contract (READ-ONLY)

Full spec: [`docs/asset-contract.md`](docs/asset-contract.md) (schema v1; sample in `docs/manifest.sample.json`).

- **Visual Asset Producer (VAP) owns `assets/frames/`**, including `assets/frames/manifest.json`. Claude Code may **consume** them; never edit, move, delete, or regenerate them. We only commit them unchanged as delivered.
- Contract changes are proposed in the team chat and agreed first; then update the doc, sample, `src/frames/manifest.ts` and tests together.
- Layout: `assets/frames/<clip>/<desktop|mobile>/0001.webp`; manifest paths are relative to `assets/frames/`.
- `src/frames/manifest.ts`: types, `parseManifest` validator (reports all problems), `framePath`, `resolveHeroFrame`, `buildTimeline` (pure, no DOM).
- The app loads `/assets/frames/manifest.json` when present, else the placeholder fallback `/placeholder-frames/manifest.json`. Override with `VITE_FRAMES_BASE`.
- **Placeholder frames** (`scripts/gen-placeholder-frames.ts`): built from `docs/manifest.sample.json` (validated via `parseManifest`) into `public/placeholder-frames/` — 540 WebP files + manifest, gitignored and generated on `predev`/`prebuild` to keep the repo light. Flags `--if-missing`, `--force`. Hero (clip first/last) frames are drawn identically across clip boundaries.
- **The placeholder fallback is ours**: `public/placeholder-frames/` is generated by `npm run frames:placeholder` and **gitignored** — never commit it, never write it into `assets/frames/`.

## Architecture (rebuild)

Page is complete static HTML (`index.html`, content panels are real DOM text); JS is progressive enhancement. `main.ts` loads the manifest and the code-split engine in parallel, never blocking first paint; on failure it drops `html.scroll-mode` and the static layout remains.

| Module | Responsibility |
| --- | --- |
| `src/frames/manifest.ts` | Types, `parseManifest`, `buildTimeline` (pure). |
| `src/frames/source.ts` | Resolve frames base (`VITE_FRAMES_BASE` → `/assets/frames/` → `/placeholder-frames/`); returns `{ base, manifest, isPlaceholder }`. |
| `src/frames/variant.ts` | Pure: `pickVariant` (portrait or <768px → mobile), `canvasPixelSize` (DPR cap 2 / 1.5 mobile), `computeFit` (cover desktop, contain mobile). |
| `src/frames/loader.ts` | `FrameLoader`: prioritised, concurrency-limited fetch → `createImageBitmap` (fallback `<img>.decode()`); `nearestLoaded`, `prioritize`, abort/dispose. Pure helpers `buildLoadOrder`, `nearestIndex`, `nearbyMissing`, `insertSorted`. |
| `src/frames/scrollMap.ts` | Pure: progress 0..1 → frame index with hold segments at each hero (`holdWeight` × average transition weight). |
| `src/frames/player.ts` | `FramePlayer`: canvas, rAF-coalesced drawing, debounced resize/orientation, variant switch (rebuilds timeline + loader, keeps progress). |
| `src/scroll/panels.ts` | Pure: panel→hero resolution (`data-hero` / `data-at`), active test, progress→scrollY. |
| `src/scroll/engine.ts` | `#scroll-track` with sticky stage + sticky panel overlay; ScrollTrigger scrub tween supplies progress; reduced-motion switches to static stills (`<img>` + alt from `data-still-alt`). |

Panels: headline → `start` (badminton), projects → golf, hobbies → dogs, experience → engineer; `#contact` is a normal section after the track. Inactive panels stay in the accessibility tree (opacity + `pointer-events: none` only); focusing a link in one scrolls to its hold.

Terminal mounts into `#terminal-root` after first paint (`requestIdleCallback`, `setTimeout` fallback). `src/terminal/commands.ts` (pure: old-site copy for help/portfolio/links, new profile copy via `CURRENT_EMPLOYER_CLAUSE`, registry, `runCommand`, `complete`), `src/terminal/lineEditor.ts` (pure key → buffer/writes/submit state machine), `src/terminal/Terminal.ts` (`mountTerminal`: toggle button + non-modal dialog; xterm and its CSS are dynamically imported only on first open or toggle hover/focus, so they are not in the entry chunk; `screenReaderMode` on, plus a visually-hidden command list and resume link; Escape closes and returns focus). Deviation from the original: `runCommand` trims input and matches the first whitespace-separated token.
